0.8

Now also worsening files from official DLCs. Yay!
Program now backups original files. But only them. Worsening changed files will not rewrite original backups.
Program corrupts multiarray (with many frames) textures, so we ignore them.
Can't open worsened textures with 1 height, so we ignore them and textures with 1 width too.
Added assets/textures/ui/ path to GUI category.
Decreased texture size limit to 1 byte.
Changed default settings.
Cat files saved without BOM header.

0.8.0.1

Multiarray textures will be resized using TRIANGLE filter.
Program window is now sizable.
Added button to restore original files.

0.8.0.2

Added assets/legacy/textures/map/ and assets/textures/map/ paths to FX category.
Added ability to remove mipmaps from GUI textures without resizing.

0.8.0.3

Game uses uncompressed mipmapless greyscale fonts, so non-UI fonts option replaced with option to compress all fonts with BC4 algorithm and additionally compress with GZip. This doesn't affect debug console dejavu font.
